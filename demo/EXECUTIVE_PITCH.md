# ChangeGuard — executive pitch video

**Runtime:** 1 minute 53 seconds  
**Format:** 1920 × 1080, H.264 video with AAC audio

## Narration transcript

1. **The problem** — Software teams are shipping faster with coding assistants. But many AI-generated pull requests still miss edge cases, break contracts, and push risk downstream. ChangeGuard closes that gap.
2. **The control plane** — ChangeGuard is a continuous test intelligence layer across frontend and backend repositories. One dashboard shows protection score, cumulative test corpus, repository health, and breaking risks, updated after every validated run.
3. **Change-focused generation** — At pull request time and on a nightly schedule, the runner maps recent changes, redacts secrets, and asks the model for boundary, authorization, contract, retry, and failure-path tests, not generic test volume.
4. **Evidence gates** — Every candidate is treated as untrusted. It cannot overwrite files, escape approved test directories, or use network and process side effects. The full suite must pass twice, and mutation gates can prove the test catches a real fault.
5. **Compounding corpus** — Passing candidates become reviewable test-only artifacts. Once merged, they join the permanent regression corpus, so every day of learning strengthens every future pull request.
6. **Actionable risk** — When the baseline breaks, or a new test exposes a regression, ChangeGuard records reproducible evidence, highlights the affected repository, and sends an alert. Executives see risk and progress without reading CI logs.
7. **The outcome** — The outcome is faster delivery without trading away confidence: fewer escaped defects, stronger contracts between frontend and backend, and a test corpus that compounds over time. ChangeGuard turns every change into stronger protection.
